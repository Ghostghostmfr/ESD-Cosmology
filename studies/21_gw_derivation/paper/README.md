# Study 21 paper notes

Second applicability companion to Study 19 (after Study 20). Axioms
(A1) and (A2) both fail for GWs (vacuum tensor perturbation; no
localized massive subsystem; no proper acceleration). R(u) does NOT
modify GW propagation.

Confirmed predictions:
- c_GW = c exactly (GW170817 bound |c_GW-c|/c < 3e-15: 0 deviation)
- Two tensor polarizations only (h_+, h_x)
- GW amplitude h ~ 1/D_L with ΛCDM D_L inherited from Study 20
- LIGO standard-siren H_0 (70 +12/-8 km/s/Mpc) consistent with
  ESD-locked H_0 (67.36) at 0.22σ

Strong falsifiers: GW-EM speed mismatch, any scalar/vector GW
polarization mode (LISA, Cosmic Explorer probes).
