# Paper note — Study A10 (UDG kinematics, broader sample)

## Scope

Same EFE-aggregation predictor as Study A07, applied to the broader
UDG population: AGC 114905 (no-DM HI disk), NGC 5846-UDG1 (DM-poor
group UDG), Dragonfly 44 (DM-rich Coma UDG), DGSAT I (isolated
diffuse), and the NGC 1052 pair (DF2/DF4) for cross-check.
